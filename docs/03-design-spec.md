# 03 — UI 设计规范

> 本文档描述当前实现（全部 UI 按 SwiftUI 标准构建，界面文案随语言本地化），适用于 v1.1。

## 1. 设计理念

- **SwiftUI 标准**：语义化颜色 / 语义化字体 / 系统组件（Form、ContentUnavailableView、MenuBarExtra）
- **简洁**：减少视觉噪音，聚焦内容本身
- **直观**：操作意图一目了然，无需学习
- **轻量**：不打扰用户工作流，即用即走

## 2. 色彩（语义化）

不写死色值，全部使用 SwiftUI 语义颜色，系统浅色/深色自动适配：

| 用途 | 语义色 | 说明 |
|------|--------|------|
| 正文 | `.primary` | 标题和正文 |
| 辅助信息 | `.secondary` | 时间标签、说明文字 |
| 强调 / 置顶 | `.tint` / `.accentColor` | 置顶标识线、图标高亮 |
| 卡片悬停底 | `Color.primary.opacity(0.05)` | 悬停反馈 |
| 搜索框底 | `.quaternary.opacity(0.5)` | 胶囊搜索背景 |
| 删除 | `.red` | 删除按钮 |
| 成功反馈 | `.green` | 复制成功勾选 |
| 类型图标 | `.blue / .green / .red / .orange / .purple / .gray` | 按文件类型着色 |

## 3. 字体（语义化）

不写死字号，使用系统语义样式：

| 用途 | 样式 |
|------|------|
| 区块标题 | `.headline` / Form Section header |
| 卡片正文 | `.body`（默认） |
| 时间 / 辅助 | `.caption` |
| 置顶分组头 | `.caption.weight(.medium)` |
| 快捷键展示 | `.system(.title3, design: .monospaced)` |
| 空状态 | `ContentUnavailableView` 默认 |

## 4. 场景与组件

### 4.1 场景架构

```
ClistoryApp
├── MenuBarExtra → MenuBarPanelView     // 菜单栏点击
├── Window(id:"main") → MainContentView // 主窗口
└── Settings → SettingsView             // 设置
```

### 4.2 菜单栏面板（MenuBarPanelView）

```
┌─────────────────────────────┐
│  🔍 搜索复制历史...          │  ← SearchFieldView（圆角 10）
├─────────────────────────────┤
│  ┃ 📌 这是置顶的复制内容     │  ← ClipboardItemCard（置顶左侧 3pt tint）
│  ┃    2分钟前          📍🗑 │
├─────────────────────────────┤
│    📝 hello world            │  ← 普通卡片
│      5分钟前          📌🗑  │
├─────────────────────────────┤
│    📄 report.pdf 等3个文件   │  ← 文件卡片（扩展名图标）
│      1小时前          📌🗑  │
├─────────────────────────────┤
│  共 N 条记录      🪟 ⏻   │  ← 底部工具栏（打开主界面 / 退出）
└─────────────────────────────┘
```

- 面板宽度：320pt，高度：480pt
- 卡片圆角：8pt，卡片间距：约 2pt（纵向 padding）
- 内边距：12pt

### 4.3 卡片（ClipboardItemCard）

- 左侧：类型图标（28×28 圆角方块 + 底色）+ 内容预览（最多 2 行）
- 右侧：悬停显示置顶/删除；复制成功显示绿色勾选（弹簧动画）
- 置顶卡片：左侧 3pt `.tint` 竖条
- 文件图标按扩展名映射 SF Symbol（文档/表格/演示/代码/压缩包/图片/文件夹）

### 4.4 主窗口（MainContentView）

```
┌──────────────────────────────────────┐
│  📋 历史粘贴板              共 N 条   │  ← 标题栏
├──────────────────────────────────────┤
│  [🔍 搜索框]                          │
│  [大卡片列表]                         │
│                                      │
├──────────────────────────────────────┤
│  点击卡片可复制到剪贴板               │  ← 状态栏
└──────────────────────────────────────┘
```

- 窗口尺寸：680 × 480pt（可调整）
- 布局：标题栏 + 搜索 + 历史列表 + 状态栏（无侧边栏）
- 标题栏应用名随语言本地化：英文界面为「Clistory」，中文界面为「历史粘贴板」
- 设置入口：菜单栏应用菜单（名称随语言，英文为「Clistory」、中文为「历史粘贴板」）→「设置…」（⌘,）

### 4.5 设置（SettingsView）

系统标准 `Form` + `formStyle(.grouped)`：

| Section | 控件 |
|---------|------|
| 语言 | 弹出式菜单：**跟随系统（Follow System，默认）/ 简体中文 / English**，位于表单顶部 |
| 存储时长 | 分段选择：**1 天 / 5 天 / 7 天 / 30 天 / 无限制** + 说明 Footer |
| 存储条数 | 分段选择：10 / 20 / 50 / 100 / 200 / 无上限 |
| 快捷键 | 等宽字体展示 + 录制快捷键 + 恢复默认 |
| 启动 | 开机自动启动 Toggle |
| 关于 | 应用 / 版本 / 简介 |

#### 4.5.1 语言分区

- **位置**：设置表单顶部（第一个 Section），排在「存储时长」之前
- **控件**：弹出式菜单（`Picker` + `.menu` 样式），Section 标题「语言」（图标 `globe`），行标签「界面语言」（英文 `Interface Language`）
- **选项与文案**：

| 设置值 | 中文界面文案 | 英文界面文案 | 说明 |
|--------|--------------|--------------|------|
| `system` | 跟随系统 | Follow System | **默认值**；跟随系统语言，未知语言回退英文 |
| `zh-Hans` | 简体中文 | 简体中文 | 固定简体中文（始终以本语言显示，不翻译） |
| `en` | English | English | 固定英文（始终以本语言显示，不翻译） |

- **即时行为**：选择后立即保存并切换应用内文案；实际生效语言未变化时不弹窗
- **辅助说明**（Footer）：「默认跟随系统。更改语言后需要重启应用才能完全生效。」

#### 4.5.2 重启提示框

- **触发时机**：语言切换后实际生效语言发生变化时弹出
- **形式**：AppKit `NSAlert`（`alertStyle = .informational`）；设置窗口有 key window 时以 sheet 形式显示，否则 `runModal()`
- **标题 / 正文**：「需要重启应用」；正文说明语言已切换，立即重启可完全应用，稍后重启则当前界面立即切换、系统级文字下次启动后更新
- **按钮**：

| 按钮 | 角色 | 行为 |
|------|------|------|
| 立即重启 | **默认按钮**（`keyEquivalent = "\r"`，回车触发） | 调用 `AppDelegate.relaunchApp()` 重启应用，全部文案完全切换 |
| 稍后重启 | 次按钮（`keyEquivalent = "\u{1b}"`，Esc 触发） | 关闭弹窗；应用内界面已切换，系统级文案留待下次启动 |

- **不弹窗条件**：切换后实际生效语言与切换前相同（例如系统已是英文时选择 English），仅保存设置
- 提示框文案走 `Settings` 字符串表（`settings.restart.*`），宽度与系统标准 Alert 一致

### 4.6 空状态（EmptyStateView）

- 使用 `ContentUnavailableView`
- 无记录：tray 图标 +「暂无复制记录」
- 搜索无结果：magnifyingglass 图标 +「未找到匹配内容」

## 5. 交互规范

- 点击卡片 → 复制到剪贴板 + 弹簧勾选动画
- 悬停卡片 → 浅色底 + 显示置顶/删除按钮
- 删除 → 直接删除不确认
- 搜索 → 实时过滤（文本 / 文件名）
- 文件失效 → SwiftUI Alert「文件已被移动或删除」→ 确定后自动删除记录
- 全局快捷键 → 唤起快捷面板（失焦自动关闭）
- 切换语言 → 应用内界面文案立即切换；若实际生效语言变化，弹出重启提示框（默认「立即重启」，回车触发）；无变化时只保存设置、不弹窗
