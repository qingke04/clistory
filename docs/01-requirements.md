# 01 — 产品需求文档

> 本文档描述当前产品需求，适用于 v1.1。

## 1. 产品定位

**Clistory**（中文名「历史粘贴板」）是一款 macOS 历史粘贴板管理器。自动记录用户复制的内容，随时回溯和再次使用。

## 2. 目标用户

- 频繁复制粘贴的文字工作者、开发者
- 需要回溯复制历史的普通用户

## 3. 功能需求

### 3.1 复制内容记录
- **文字**：纯文本、富文本（提取纯文本存储）
- **文件/文件夹**：记录文件路径（不保存副本），支持多文件合并为一条记录
- **图片文件**：与普通文件一致，记录路径
- **剪贴板图片数据**（截图、网页复制的图片等）：**跳过不记录**
- 自动记录，无需手动操作；隐藏文件（以 `.` 开头）自动过滤

### 3.2 历史浏览
- 以**时间降序**排列（最新在最上面）
- 置顶项始终在最顶部（独立分组）
- 卡片式展示：内容预览 + 时间标签

### 3.3 搜索
- 支持文字内容搜索（模糊匹配）
- 实时过滤，输入即搜

### 3.4 内容操作
- **置顶/取消置顶**：重要内容固定在顶部
- **删除**：移除不需要的记录（文件记录只删条目，不删源文件）
- **复制到剪贴板**：点击后内容恢复到系统剪贴板
  - 文字记录：写回纯文本
  - 文件记录：将原路径文件重新复制到剪贴板（可在 Finder 粘贴）
  - 文件已失效：弹窗提示「文件已被移动或删除」，并自动删除该条记录

### 3.5 存储管理
- 可设置存储时长：**1天 / 5天 / 7天 / 30天 / 无限制**
  - **无限制**：不根据时间删除历史记录
- 可设置存储条数上限：**10 / 20 / 50 / 100 / 200 / 无上限**
- 超过时长或条数的记录自动清理（置顶项不自动清理；「无限制」时不按时间清理）
- 文件记录清理时只删元数据，不删除源文件

### 3.6 快捷访问
- 菜单栏图标点击弹出面板
- 全局快捷键唤起面板（默认 `Cmd+Shift+V`）
- 快捷键可在设置中自定义

### 3.7 开机自启动
- 支持开机自动启动
- 设置中可手动开关

### 3.8 两种界面
- **菜单栏面板**：搜索、浏览、基础操作（置顶/删除/复制）
- **主窗口**：完整管理、设置页面

### 3.9 界面语言设置
- 设置 →「语言」提供三个选项：**跟随系统（Follow System，默认）**、**简体中文**、**English**
- 选择后应用内界面文案立即切换，无需重启
- 若切换后实际生效语言发生变化，弹出重启提示框：
  - **立即重启**（默认选中，回车触发）：重启应用，应用内界面与系统级文案（应用菜单名、系统「设置…」菜单等）完全切换
  - **稍后重启**：应用内界面立即切换；系统级文案在下次启动后完全切换
- 若切换后实际生效语言没有变化（例如系统已是英文时选择 English），只保存设置，不弹出提示
- 应用显示名称随语言本地化：英文为 Clistory，简体中文为历史粘贴板

## 4. 非功能需求

- 应用启动后对系统性能影响尽可能小
- 数据存储在本地，不联网

## 5. 不做的功能（当前版本）

- 不保存图片/文件副本（只记录路径；截图等图片数据不记录）
- 不加隐私过滤
- 不支持云同步
- 不支持富文本格式保留（只保留纯文本）

## 6. 验收标准（v1.1 语言设置）

- [ ] 首次启动默认「跟随系统」；系统语言为简体中文时界面为中文，为其他语言时回退英文
- [ ] 设置为「简体中文」或「English」后，应用内文案立即切换为对应语言
- [ ] 实际生效语言变化时弹出重启提示框，默认按钮为「立即重启」，回车可触发
- [ ] 选「立即重启」后应用重启，应用内与系统级文案均为新语言
- [ ] 选「稍后重启」后应用内文案已切换；下次启动后系统级文案（应用菜单名、系统「设置…」菜单等）完全切换
- [ ] 实际生效语言未变化时（如系统已是英文时选 English）只保存设置、不弹窗
- [ ] 英文界面下应用名显示 Clistory，简体中文界面下显示历史粘贴板
- [ ] 更名后 Bundle ID 仍为 `com.clipboardmanager.app`，历史记录不丢失
