# 01 — 产品需求文档

> 本文档描述当前产品需求，适用于 v1.0.0。

## 1. 产品定位

macOS 历史粘贴板管理器。自动记录用户复制的内容，随时回溯和再次使用。

## 2. 目标用户

- 频繁复制粘贴的文字工作者、开发者
- 需要回溯复制历史的普通用户

## 3. 功能需求

### 3.1 复制内容记录
- **文字**：纯文本、富文本（提取纯文本存储）
- **文件/文件夹**：记录文件路径（不保存副本），支持多文件合并为一条记录
- **图片文件**：与普通文件一致，记录路径
- **剪贴板图片数据**（截图、网页复制的图片等）：**跳过不记录**
- 自动记录，无需手动操作；隐藏文件（以 `.` 开头）自动过滤

### 3.2 历史浏览
- 以**时间降序**排列（最新在最上面）
- 置顶项始终在最顶部（独立分组）
- 卡片式展示：内容预览 + 时间标签

### 3.3 搜索
- 支持文字内容搜索（模糊匹配）
- 实时过滤，输入即搜

### 3.4 内容操作
- **置顶/取消置顶**：重要内容固定在顶部
- **删除**：移除不需要的记录（文件记录只删条目，不删源文件）
- **复制到剪贴板**：点击后内容恢复到系统剪贴板
  - 文字记录：写回纯文本
  - 文件记录：将原路径文件重新复制到剪贴板（可在 Finder 粘贴）
  - 文件已失效：弹窗提示「文件已被移动或删除」，并自动删除该条记录

### 3.5 存储管理
- 可设置存储时长：**1天 / 5天 / 7天 / 30天 / 无限制**
  - **无限制**：不根据时间删除历史记录
- 可设置存储条数上限：**10 / 20 / 50 / 100 / 200 / 无上限**
- 超过时长或条数的记录自动清理（置顶项不自动清理；「无限制」时不按时间清理）
- 文件记录清理时只删元数据，不删除源文件

### 3.6 快捷访问
- 菜单栏图标点击弹出面板
- 全局快捷键唤起面板（默认 `Cmd+Shift+V`）
- 快捷键可在设置中自定义

### 3.7 开机自启动
- 支持开机自动启动
- 设置中可手动开关

### 3.8 两种界面
- **菜单栏面板**：搜索、浏览、基础操作（置顶/删除/复制）
- **主窗口**：完整管理、设置页面

## 4. 非功能需求

- 应用启动后对系统性能影响尽可能小
- 数据存储在本地，不联网

## 5. 不做的功能（当前版本）

- 不保存图片/文件副本（只记录路径；截图等图片数据不记录）
- 不加隐私过滤
- 不支持云同步
- 不支持富文本格式保留（只保留纯文本）
